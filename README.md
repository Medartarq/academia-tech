# Academia Tech

Solucion de la Practica 3: pagina responsiva para una academia de cursos.

## Componentes incluidos

- Navbar con enlaces internos y menu responsive.
- Seccion principal con boton de accion.
- Tres cards de cursos.
- Modales con informacion de los cursos.
- Formulario dentro de un modal con validacion visual.
- Clases de texto, espaciado y rejilla responsive de Bootstrap.
